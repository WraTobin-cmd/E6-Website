# Etherion 6 Website

A static HTML/CSS/JavaScript starter website for Etherion 6.

## Folder structure

- `index.html` — the page
- `style.css` — design and responsive layout
- `script.js` — small interactions/animations
- `assets/e6-logo.png` — cropped E6 logo from the supplied image

## Before publishing

Replace the placeholder social links in `index.html` with the official URLs.
Add real screenshots/game artwork if you have permission to use them.
